### 需求整理

#### 1. 功能描述

在会话区消息列表中，为用户发送的气泡消息添加“编辑”功能。用户可修改已发送的内容，提交修改后将重置该节点之后的会话状态并重新生成回答。

#### 2. UI 交互逻辑

* **触发编辑**：悬停或停留在用户气泡所在组件 `.xzv4MW_action` 时，新增显示 **Edit Icon Button**。
* **状态切换**：点击 Edit 按钮后，原本的用户消息气泡 `.Sixlwa_bubble` 隐藏或转为可编辑形态。
* **编辑框样式**：
* **容器**：宽 100%（占满气泡容器宽度），带圆角，背景色为灰色。
* **输入控件**：多行/单行文本输入框，填充当前消息文本。
* **操作区**：位于输入框右下方。
* **取消按钮**：白色背景小按钮，点击退出编辑状态，恢复原本气泡。
* **发送按钮**：黑色背景小按钮，点击提交修改。
* **快捷操作**：支持按下 `Enter` 键直接确认发送（`Shift + Enter` 换行）。
* **触发运行**：确认提交后，系统**丢弃当前消息节点之后的所有历史对话与输出**，并以更新后的文本重新发起会话请求。

### 数据流与行为

```text
[点击 Edit 按钮] ──> [气泡 .Sixlwa_bubble 变为输入框]
                             │
            ┌────────────────┴────────────────┐
            ▼                                 ▼
      [点击 取消]                     [点击 发送 / 回车]
            │                                 │
            ▼                                 ▼
      [恢复原气泡]                    1. 截断该消息后的上下文历史
                                      2. 更新当前节点消息文本
                                      3. 触发系统重新发送请求

```
