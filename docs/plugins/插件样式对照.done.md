## 一、背景与原则

### 1.1 起因

用户要求把调度器面板的自绘控件（`.dsch-*` 自定义类 + `--dsw-alias-*` 令牌）换成**官方控件外观**，并点名了开发工具里看到的官方 CSS module hash 类名：

- `.zGbnIq_input` / `.zGbnIq_iconButton` / `.zGbnIq_selectInput`（官方 `ModelsSection.module.css`，属 `dsh-client-ui-settings-models` 插件）
- `.hVGvvW_selector`（官方 `LanguageRow.module.css`，属 `dsh-client-locale` 插件）
- 参考实现：`dsh-tauri-session`（其 `archive-panel.tsx` / `menu-select.tsx`）

### 1.2 调研结论（决定实现路径）

1. 上述 hash 类名是**构建期生成的 CSS module hash**，仅在其所属插件加载（`<style data-plugin-css>` 注入）时才存在于全局 DOM，且依赖 ui-theme 插件的 `--dsw-*` 令牌；**跨版本不变性无保证**；
2. `docs/AGENTS.plugins.md:223/250` 明确**禁止依赖生成的 CSS module hash**（DOM 补丁/选择器必须用稳定 slot、ARIA、插件前缀 class）；
3. `dsh-tauri-session` 参考实现**零处硬编码 hash**——用的是官方 primitives 组件 + 插件前缀类 + `--dsw-*` 令牌；
4. `.hVGvvW_selector` 不是原生 `<select>`：它是 **pill 触发按钮 + primitives `Menu`**（官方 Select 模式）。

**结论**：不引用字面 hash 类；把官方规则**逐字复制**到本插件自己的 css-render 样式表，改用稳定前缀类承载（`dsh-tauri-panel-scheduler-*`），下拉/弹窗用官方 primitives 组件（`Menu` / `Modal`）。视觉与官方一致，浅色/深色由令牌自动适配。

## 五、组件替换说明

### 5.1 `MenuSelect`（新增 `client/components/menu-select.tsx`）

- 官方 Select 模式 = pill 触发按钮 + primitives `Menu`（portal, align=end, closeOnPointerLeave, selectedId 勾选）；
- 与 `dsh-tauri-session` 的 `menu-select.tsx` 同构，外围样式换成 `K.selector`；
- 用于新建对话框 composer 的 workspace / mode / module 三项；空选项（`id:''`）带「未分组 / 默认模式 / 默认模型」文案进选项表，回选可重置。

### 5.2 对话框外壳与删除确认 → primitives `Modal`

- 新建对话框：`title`=`新建定时任务`、`description`=`dialogHint`、`closeLabel`=`close`、`footer`=取消/保存（官方 36px 按钮）；
- 关闭保护：Esc / 遮罩 / [X] 均走 `onClose={() => closeSafe()}`，`savingRef` 为真时忽略；
- 卡片删除：Menu danger 项 → `Modal` 二次确认（新文案键 `deleteConfirmTitle` / `deleteConfirmBody`，zh/en），footer 取消 / 删除（`K.btnDanger`）。

### 5.3 依赖接线（`package.json`）

- `dsh.client.inject`：`["@deepseek-ai/dsh-client-ui-layout", "@deepseek-ai/dsh-client-ui-primitives", "dsh-tauri"]`（与 `dsh-tauri-session` 一致）；
- 不进入 `dependencies`——primitives 构建为 external（`dist/client.cjs` 仅 `window.__ModuleLoader__.load({id:'dsh-tauri-panel-scheduler',…})` 内 `e('@deepseek-ai/dsh-client-ui-primitives')` 单次引用），运行时从宿主 ModuleLoader 解析。

## 六、约束与注意事项

1. **禁止依赖生成的 CSS module hash**（`AGENTS.plugins.md:223/250`）：不把 `.zGbnIq_*` / `.hVGvvW_*` 写进代码/选择器；控件值以插件前缀类 + 令牌承载。若审查方坚持字面 hash 类，需自行评估跨版本与插件常驻风险。
2. **样式一律 css-render 对象节点**（`AGENTS.plugins.md:136`），mount 仅在 `apply()` 经 `ctx.effect`（`STYLES_EFFECT`），`STYLE_ID` 幂等守卫（`cssr.find`）。
3. **插件前缀类**（`AGENTS.plugins.md:145`）：`dsh-tauri-panel-scheduler-*`，避免跨插件 `.dsch-*` 撞名。
4. **令牌注意**：`--dsw-alias-label-error` 在官方令牌集中**从未声明**（4 个官方插件样式表引用但解析无效）；一律用 `--dsw-alias-state-error-primary`。
5. **行为不改**：weekly 单选、时区（宿主本地时间）、键盘焦点陷阱、docstring 阈值（CodeRabbit 75%<80%）仍为遗留项，未在本轮处理。
6. 改动后需 `pnpm build:plugins` 重建部署（`src-tauri/resources`），浏览器刷新即可；若 `pnpm run dev:web` 的 watcher 在跑，客户端插件改动会自动重打包（需确认该 watcher 存在）。
