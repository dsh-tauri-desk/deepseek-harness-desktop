# dsh-tauri-panel-placeholder

`dsh-tauri-panel-placeholder` 是面板扩展的占位插件。它保留与正式面板包一致的加载形态，适合在开发、演示或等待真实面板实现时使用。

## 当前状态

该包只提供可加载的基础入口，不渲染实际面板，也不注册额外的 host API。需要真实面板时，请改用 [`dsh-tauri-panel`](../dsh-tauri-panel) 或等待后续实现。
