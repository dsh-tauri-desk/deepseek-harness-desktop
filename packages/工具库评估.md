## 1. pathe — 统一路径处理（host half）

- 替换宿主侧全部 `node:path`：worktree（git/storage/operation/route/session）、
  session（session-files/storage/archive）、panel-extension（repos/state/skills/
  restart/profile/rmtree/tar/agents/mcp/routes）。
- 依据：宿主文件系统路径统一规范化 POSIX 语义；Web 端不操作真实路径，无需引入。
- 保留 `node:fs` / `node:os` 等非路径 API 不变。

## 2. ofetch — 统一 HTTP 客户端（client half + 宿主下载）

- `dsh-tauri/client`（宿主 base 包）重构为 ofetch 底座：
  - `client/http.ts` → `requestJson` / `createJsonClient`（timeout / 自定义错误信息 /
    parseResponse / retry:0），并**从客户端 barrel 导出**成为全 workspace 共享 JSON 客户端；
  - `host/open.ts` 保持 spawn 逻辑不变（系统打开不需要 HTTP）。
- 各插件 client 全部接入共享客户端：
  - worktree `client/rpc.ts`（createJsonClient 绑定 /api/dsh-worktree）；
  - session `client/rpc.ts`（15s 超时 + 本地化错误文案 + resync 语义保持不变）；
  - panel-extension `client/index.ts`（错误信息优先宿主 error 字段，与旧实现一致）；
  - rightclick `client/actions.ts`（host.openPath RPC + 打开外链）。
- 宿主侧二进制下载：panel-extension `host/repos.ts` 的 GitHub tarball 改走
  `$fetch.raw(responseType: 'arrayBuffer')`（timeout 60s、关闭重试），保留可注入
  fetcher 以兼容既有测试。

## 3. unstorage — 统一持久化（fs 适配器 + 原子写）

- 宿主 base 包 `dsh-tauri/host/storage.ts` 新增共享设施
  `createAtomicFsStorage(base)`：组合 unstorage 的 fs driver，`setItem` 恢复
  tmp+rename **原子写**（unstorage fs driver 的 setItem 是直接 writeFile，读写
  半份 JSON 的隐患必须保持原设计保证）；读走 `getItem`（自动 JSON 解析）。
- 三个 JSON 状态文件全部迁移：
  - worktree `host/storage.ts`：`ledger.json` + `checkout-context.json`；
  - session `host/storage.ts`：旧版 `dsh-tauri-session/archive.json`（仅迁移期读写）；
  - panel-extension `host/state.ts`：`state.json`（add/remove 转异步）。
- 浏览器偏好：worktree `client/store.ts` 的「新会话偏好」改走 unstorage
  `localstorage` driver（base=`dsh-tauri-worktree`，driver 拼 `base:` 前缀 →
  兼容旧 localStorage key `dsh-tauri-worktree:preferred-mode`），apply 时
  hydrate 一次缓存，写入即改即存。

## 4. hookable — 生命周期/事件钩子

- 共享生命周期控制器 `dsh-tauri/client/controller.ts`：所有客户端的
  observer/timer/listener/disposer 收敛进一个 controller（dispose 为命名钩子，
  hookable `createHooks` 承载），幂等清理，异步续接以 isDisposed() 守护。
- 消费方：worktree（hydration/session 行图标）、rightclick（右键菜单）、
  dsh-tauri（导航桥）——各插件删除本地 controller.ts，统一从
  `dsh-tauri/client` 导入。
- dsh-tauri-panel `client/service.tsx`：会话区替换控制器内建
  `view:open` / `view:close` 命名钩子。
- 宿主钩子轴：
  - worktree `host/hooks.ts`：`session:turn-end`（apply 事件转发 → 钩子接线交接/上下文消费）；
  - session `host/hooks.ts`：`archive:added` / `archive:restored` / `archive:deleted`
    （归档业务状态落定后触发，插件级单例 `archiveHooks` 导出）；
  - panel-extension `host/hooks.ts`：`provider:before-remount` / `provider:after-remount` /
    `provider:error`（filesystem skill provider 重挂载状态机）。
- 未引入 hookable 的包：dsh-tauri-ui / placeholder（无真实生命周期轴，按「按真实使用面」不装）。
