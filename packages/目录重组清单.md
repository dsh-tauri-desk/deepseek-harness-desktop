# packages 目录重组清单（统一规律）

> 规律（用户给定 + 推断）：**单一职责文件 → 同名目录（index.ts barrel 聚合）**。
> - `constants.ts` → `constants/index.ts`（拆领域文件时加 `constants/*.ts` + barrel）
> - `types.ts` → `types/index.ts`（已有的 `types/*.ts` 保持；根上的 barrel 移入目录作 index.ts）
> - `locale.ts` → `locales/index.ts`
> - `rpc.ts` → `apis/client.ts` + `apis/index.ts`（barrel）
> - `styles.ts` → `styles/index.ts`
> - `icons.ts(x)` → `components/icons.tsx`（含 JSX 必须保留 .tsx）
> - `lib/` → `utils/`
> - `features/` → `components/`
> - `markdown-preview.tsx` → `components/markdown.tsx`
> - `state.ts`/`state/`（client）→ `config/index.ts` / `config/`
> - `store.ts` → `store/index.ts`（拆领域时加 `store/*.ts`）
> - `handoff.ts`（client）→ `service/handoff.ts`
> - `hydration.ts`（client 安装器）→ `register/hydration.ts`
> - `dom/session-icons.ts` → `register/session-icons.ts`
> - `sidebar.tsx`（组件+安装器混合）→ `components/sidebar.tsx` + `register/sidebar.ts`
> - 其余 `install*`/`register*` → `register/`
> - Host：`agents/mcp/opener/profile/repos/restart/rmtree/skills/tar/handoff/session/operation/git/archive/registry/session-files` → `service/`
> - Host：`route.ts`/`routes.ts` → `routes/index.ts`（已有 `routes/*.ts` 保持）
> - Host：`state.ts`/`storage.ts` → `storage/index.ts`
> - Host：`hooks.ts` → `hooks/index.ts`
> - Host：`tools.ts` → `tools/index.ts`
> - Host：`apply.ts` 保持原位
>
> 规则：只移动/改名/收口 barrel，**公开导出面（barrel 导出的名字）不得变化**；全部相对导入同步更新；
> `src/index.ts` 与 `src/client/index.ts` 入口路径不变（tsdown 配置不动）。
>
> ⚠️ 导入路径注意：
> - client 用 bundler 解析：`'./constants'` / `'./types'` / `'./store'` 等旧写法仍能解析到目录 index.ts，
>   但为一致起见应显式更新为目录导入（`'./constants'` 解析 `constants/index.ts`，保留即可；若导入的是
>   `'./constants'` 且目标就是 index，可不动）。凡指向被移动的单文件（如 `'./rpc'`、`'./locale'`、
>   `'./clipboard'`）必须改成新路径（`'./apis'`、`'./locales'`、`'./utils/clipboard'`）。
> - host 用 Node ESM + 显式 `.js` 后缀：被移动文件的导入必须把 `./xxx.js` 更新为新位置
>   （如 `./types.js`→`./types/index.js`、`./route.js`→`./routes/index.js`），否则运行时解析失败。
>
> 验证：每包完成后跑 `pnpm --filter <pkg> exec tsc --noEmit -p .` 必须绿。
